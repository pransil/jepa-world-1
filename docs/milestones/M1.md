## Built

[`jepa_world/sim/DESIGN.md`](../../jepa_world/sim/DESIGN.md) has the shapes, decisions and seams.

| module | role |
|---|---|
| `terrain.py` | seeded y-constant profile: red-noise sinusoids (relief drawn, slope-capped) + 2–5 smoothed ledges + end walls; exact polyline geometry (`gap`, `slope_at`), float32 hfield encoding |
| `ball.py` | hidden radius, friction and restitution, plus the initial state, from their own seed stream |
| `contact.py` | restitution → direct-mode solref damping via a measured calibration table; friction triple (sliding f, 0, rolling 0.01·f) |
| `scene.py` | MJCF: hfield, ball on slide-x/slide-z/hinge-y joints, orthographic camera on a mocap rig, flat shading |
| `camera.py` | `track_lagged` / `track_full` tracking, orthographic projection, out-of-view rule (pure) |
| `episode.py` | `simulate_episode(sim_cfg, terrain_seed, ball_seed, render, segmentation)` → `Episode`; `simulate` for a given terrain and ball; `ContactTracker` (per-substep contact and bounce) |
| `render.py` | RGB and per-pixel geom-id segmentation (the only GL code) |
| `io.py` | `save_episode` / `load_episode`: compressed npz plus JSON metadata, no pickle |
| `preview.py` | CLI: contact sheets plus `stats.json` in a run dir |

## Proven by

| SPEC §8 M1 test | test name(s) | tier |
|---|---|---|
| Deterministic regeneration from seed (ground truth) | `test_sim_episode.py::test_same_seeds_regenerate_identically`, `::test_ball_seed_changes_the_ball_but_not_the_terrain`, `test_sim_terrain.py::test_same_seed_gives_identical_terrain` | fast |
| Deterministic regeneration from seed (frames, byte for byte) | `test_sim_render.py::test_same_seeds_render_identical_frames`, `::test_rendering_does_not_change_physics` | render |
| Per-frame GT matches rendered geometry | `test_sim_render.py::test_ball_pixels_match_ground_truth` (segmentation centroid within 0.5 px of `ball_px`, area within the ±0.75 px radius band, out_of_view ⇒ no ball pixels), `::test_terrain_pixels_match_the_profile` (top terrain pixel per column within 1 + slope/2 px of the projected profile) | render |
| … its geometry oracle | `test_sim_contact.py::test_mujoco_contact_agrees_with_the_terrain_polyline` (MuJoCo contacts vs `Terrain.gap`, ledges included), `test_sim_camera.py::test_projection_centre_edges_and_orientation` | fast |
| Event flags consistent with GT | `test_sim_episode.py::test_no_contact_means_an_exactly_ballistic_step` (1e-9), `::test_no_contact_means_the_ball_is_above_the_surface`, `::test_ball_never_sinks_into_the_terrain`, `::test_bounce_is_a_contact_whose_impulse_points_up`, `::test_tracker_*` (the bounce thresholds), `::test_flat_drop_bounces_at_the_predicted_frame_then_settles`, `::test_camera_and_pixel_ground_truth_follow_the_camera_rules`, `::test_occluded_is_all_false_without_obstacles`, `::test_events_are_not_degenerate` | fast |

Seen to fail: every test file failed on ImportError before the code existed. Then nine behaviour
mutations were applied, one at a time, each restored afterwards, and each was caught:
- contact flags without substeps;
- hfield one column off;
- flipped image v;
- stale camera pose (`mj_kinematics` instead of `mj_forward`);
- inverted restitution;
- constant rolling drag;
- bounce without its airborne-time rule;
- bounce without its approach-speed rule;
- an unseeded terrain RNG.

The two bounce mutations survived the first test set. `test_tracker_*` was added for them, in
response to /verify.

Final test runs (commit 7b9cb5a plus this summary): see the PR body for the RESULT lines.

## Open issues / deferred

- **Obstacles and occlusion** are deferred to M7. `occluded` is recorded and is always False.
- **Out-of-view comes only from deep drops** (ledges). No high bounce leaves the top of the frame
  at these settings. If M6 needs more or different events, the knobs are `camera.lerp_z`,
  `camera.deadzone_z`, `terrain.ledges` and `terrain.ledge_height`. Bump
  `sim.generator_version` only if the code changes; a config change already changes the hash.
- **Low-speed restitution** is below nominal for low e: about 0.12 at 1 m/s for e = 0.2, because
  gravity acts during the ~20 ms contact. It is within ±0.03 from 3 to 9 m/s.
- **Smooth terrain alone** gives 3% out-of-view episodes (`d3d986`). That is why ledges were
  added. It is worth knowing if anyone simplifies the terrain.
- **For M2:**
  - splits and datasets go through `paths.build_dataset_once`, keyed on the `sim` config;
  - the generator's event rates were tuned on terrain seeds 0–199. No model metric was involved,
    but M2 may prefer test seeds outside that range;
  - determinism is proven on one machine. Across platforms, numpy transcendentals and the GL
    stack may differ, so build each dataset on one machine and store `repro.run_metadata()`
    with it (DESIGN.md, "Determinism scope");
  - `simulate(sim_cfg, terrain, ball)` re-runs known terrain, which the physics baseline can use.
