Seen to fail: every new test file failed on ImportError or a missing unit before the code
existed. Then 25 behaviour mutations were applied one at a time, each restored afterwards, and
each was caught by its named test. Among them:
- hard clamp instead of tanh;
- NLL target not detached, or no log 2π, or averaged over channels;
- inactive horizons entering the total;
- guard averaged over levels;
- inactive heads keeping autograd;
- stage start off by one;
- far head reading the wrong level;
- plus the M3 stop-grad, EMA and leakage mutations, re-run on the M4 code.

## Measured

- **Step time on MPS, B = 32, SPEC shapes** (`python -m jepa_world.bench`, commit 67ab30d, before
  the review's `no_grad` change, machine load not recorded):
  - near + far 158.1 ms vs near only 104.5 ms (`runs/…-bench-l1-heads-337448` vs `…-9542d0`);
  - with 32-wide far heads 143.9 ms (`…-2e1860`), so the full-width far heads cost about 14 ms;
  - MPS driver memory 3.3 GB vs 2.1 GB;
  - no op fell back to CPU.
  - Later timings in this lane were taken at load average ~250 (other processes) and are not
    reported.
- **Far collapse** ([experiment](../../experiments/2026-11-17-m4-far-collapse.md), dev split =
  debugging only):
  - With the old guard (mean, w_var 1), L3 std dipped 0.35 → 0.097 when far joined, and the far
    log-variance ran to −4…−5.
  - With the shipped guard (sum, w_var 25), L3 std rose to 1.08, and log-variance stayed near
    −1…−0.4.
  - relerr at 600 steps: k1 0.07, k5 0.26, k10 0.66, k20 0.89 (`runs/20261118T053203Z-…-dev-guardsum-df9b23`).

## Open issues / deferred

  longer train-split run with several seeds before M5's goal head reads pooled L3
  (see the decision file).

  It is still to be added, together with `docs/milestones/M3.md`.
- **The far NLL's ½ factor vs the near squared error:** at logvar 0, a far head's mean gets
  half the near weight. This is documented in DESIGN.md. `w_k` is a SPEC placeholder, to be
  tuned by ablation.
- **The log-variance floor (−10)** is unchanged. Under the shipped guard, logvar stays near −1,
  far from the floor.
