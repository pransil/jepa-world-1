# M6: Evaluation and probes

- **Completed:** 2026-11-17 (code; the headline model numbers come from the headline run, below)
  **PRs:** #10 (metrics, probes), #18 (simulator-aware baseline), this PR (`eval --run`)

## Built
Design: [jepa_world/DESIGN.md](../../jepa_world/DESIGN.md).
- `metrics.py`, pure numpy:
  - position error and ratio to persistence by horizon;
  - 50/90% calibration of a diagonal Gaussian, per axis and joint;
  - rollout drift;
  - event-locked uncertainty around out-of-view/occlusion onsets and offsets;
  - hidden-vs-visible std ratio and coverage;
  - `SplitResult`/`report`, where only test can be the headline.
- `probes.py`: StandardScaler + RidgeCV linear probes on frozen pooled levels L1/L2/L3/pooled. It
  never fits on test and never scores a training terrain.
- `baselines.py`: the simulator-aware physics baseline (SPEC §7.1). It re-simulates the known
  terrain from the true state at t, maps a non-true radius by clearance along the surface normal,
  and has params `true`, `mean` and `true_radius`.
  [Proposed decision](../decisions/2026-11-17-simulator-baseline-params.md).
- `eval.py --run`: scores a trained run on held-out splits, test as the headline and dev
  separate. It covers goal-head error, ratios to every baseline, calibration, drift,
  visibility, events and probes. Everything is on the baselines' windows, and the report goes
  to `<run>/eval/*.json`. `configs/base.yaml` has an `eval:` block.

## Measured
- **Baselines on test** (200 episodes, 7400 windows, t = 3..39; run
  `runs/20261118T065246Z-worktree-wt-sim-baseline-baselines-test-590f46`). Ratio of mean error to
  persistence at k = 1 / 5 / 20:

  | baseline | k = 1 | k = 5 | k = 20 |
  |---|---|---|---|
  | const_velocity | 0.174 | 0.568 | 1.211 |
  | simulator `mean` | 0.014 | 0.055 | 0.080 (0.137 m) |
  | simulator `true_radius` | 0.010 | 0.048 | 0.072 |
  | simulator `true` (oracle) | 0.000 | 0.000 | 0.000 (1.0e-5 m) |
- **`eval --run` end to end on a real run.** first-real-s1 is pre-M5, so it has no goal head and
  this checks only probes and baselines. On MPS:
  `runs/20261118T060158Z-worktree-wt-exp-first-real-run-first-real-s1-72abd4/eval/20261118T071819Z-test-dev-9ff2cb.json`.
  Probe R² on test, with 4000 train windows and the pooled levels:

  | target | R² |
  |---|---|
  | camera-relative position `pos_cam` | 0.73 |
  | radius | 0.85 |
  | restitution | 0.05 |
  | friction | ≈ 0 |
  | world position | ≈ 0 |

  World position isn't in a tracking camera's frame, which is why `pos_cam` was added.
- **Cost.** Each simulator params option takes 46–85 s on test at moderate load, and 7–11 min at
  load average ~265.
